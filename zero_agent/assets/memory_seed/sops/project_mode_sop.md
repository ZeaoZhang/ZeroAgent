# Project Mode SOP

## 定义

Project Mode = 通过已授权的 local_v1 项目上下文保持项目认知的工作模式。项目身份由 RuntimeContext 和 ContextAdminService 绑定；项目记忆只存在于 `za://projects/<id>/memories`，由 context 服务按授权读取和写入。

## 进入

- 用户明确进入或切换项目时，使用当前入口提供的项目绑定流程；不得用工作区文件、进程标识或未授权文本确定项目身份。
- 需要项目背景时，先按当前任务相关性查询已授权的项目记忆，再将必要内容用于任务。
- 读取失败、项目未绑定或无权限时停止，而不是回退到本地文件记忆。

## 期间纪律

- 项目文件（todo、草稿、产物）放在选定的 workspace 目录；workspace 只负责目录选择和安全的目录联接。
- 值得跨任务复用的用户明确结论，通过 `memory_update` 按记忆服务的来源、权限和持久意图规则写入项目记忆。
- 不直接修改记忆存储目录，不把模型推断或普通文件内容伪装成已授权项目记忆。

## 离开

项目绑定随当前 RuntimeContext 和任务边界结束；不创建或清理进程锚点。需要切换项目时，重新建立经过授权的 RuntimeContext 项目绑定。
